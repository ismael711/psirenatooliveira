Coloque suas imagens nesta pasta seguindo os nomes abaixo.
O site já referencia cada arquivo diretamente — basta substituir.

## 📂 assets/icons/

Reserve esta pasta para ícones SVG personalizados, se precisar adicionar futuramente.

---

## ✅ Formatos aceitos

- **JPG / JPEG** — recomendado para fotos (menor tamanho)
- **PNG** — use para fotos com fundo transparente (recorte)
- **WebP** — melhor performance se o site estiver em servidor

## 🔒 Dica de qualidade vs. performance

- Fotos de fundo (hero, empresas): comprimir para **200–400 KB**
- Fotos de rosto (renato-hero, renato-sobre): máximo **300 KB**
- Use [squoosh.app](https://squoosh.app) para comprimir sem perder qualidade visível
